表示中の日時とビューは URL に反映されます (?t= / view)。 観測地は都市プリセットのときだけ名前で反映され (city)、 それ以外の座標 (現在地の取得・手入力) はアドレスバーには出ません。 緯度経度を含む URL は、この共有ダイアログで選んだときだけ作られます。

表示

人工衛星は ISS・CSS・ハッブルの軌道要素 (TLE) を内蔵しています。 TLE は取得時点 ({{TLE_DATE}}) のスナップショットのため、基準日時から離れるほど位置誤差が増えます。 航空機の表示にはリアルタイム ADS-B データが必要なため、本ツール (オフライン単一ファイル) には含めていません。

2D: ピンチ/ホイールで拡大、拡大中はドラッグで移動。3D: ドラッグで視線移動、ピンチ/ホイールで画角。 天体をタップすると情報を表示します。

🧭 は 3D ビューで端末の向きに視線を追従させます (要ジャイロ/コンパス。iOS は初回にセンサー許可が必要)。 方位がずれる場合はセンサー動作中に左右ドラッグで補正できます。 file:// で開くとセンサー許可が得られない端末では、Web サーバ経由 (https) で開いてください。

データ出典: HYG v4.1 (CC BY-SA 4.0) / d3-celestial (BSD-3) / CelesTrak TLE。 ライブラリ: three.js r147, satellite.js 4.1.4 (MIT)。 位置計算は Meeus の略算式によります (表示用途向け)。
